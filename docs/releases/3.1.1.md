# Tag Check 3.1.1

Tag Check 3.1.1 is a security release. The desktop app runs its backend on
a bundled Node.js, and 3.1.0 shipped Node.js 24.22.0. 3.1.1 bundles
Node.js 24.22.1, which fixes the Node.js security issues published on
October 20, 2026. The app itself is unchanged.

## Security

- The bundled Node.js moves from 24.22.0 to 24.22.1. Node.js lists eight
  issues that affect the 24.x line, four rated high:
  - an out-of-bounds write in the Brotli decoder (CVE-2026-111497);
  - DNS name truncation at a null character (CVE-2026-105482);
  - two ways to bypass TLS hostname verification (CVE-2026-105483,
    CVE-2026-106069).

  The backend fetches the sites under test and Google Tag Manager over
  HTTPS, so these fixes apply to it. See the Node.js release notes for
  24.22.1 for the full list.

## Upgrading

Install 3.1.1 over 3.1.0. The database, projects, Tests and Runs are kept.
