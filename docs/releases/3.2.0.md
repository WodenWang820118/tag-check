# Tag Check 3.2.0

Tag Check 3.2.0 is the release after 3.1.1. It runs selected Tests as a
batch, records the GTM Tag Assistant tab next to the site in accompanied
mode, lets tag-build start from a GA4 measurement plan, and fixes many bugs
found in a review of the whole app.

## Highlights

- Run selected Tests as a batch, one after another, with progress, cancel
  and resume after a reload or restart. Batches work in accompanied mode;
  each Test's browser closes when its run ends. (#540, #544)
- Accompanied-mode runs record two views: the site's journey and the Tag
  Assistant tab listing the tags as they fire. The Reports tab shows both.
  (#543)
- Runs happen one at a time on the backend, whoever starts them. Stop ends
  the running Test and drops the Tests waiting behind it. (#542, #554)
- tag-build reads a GA4 measurement plan: download the CSV template of
  Google's recommended events, keep the events the site needs, and upload
  it to build the GTM container. (#530)
- tag-build containers import into Tag Manager with their measurement ID
  set, as Tag Manager itself exports GA4 tags. (#547)

## Changes

### Tests and runs

- **Run selected** starts a batch with the selected Tests in table order.
  The batch panel shows each Test's outcome and the reason for a failure,
  and keeps a cancelled Test as Cancelled. (#540, #548)
- A run's progress reaches the app over Server-Sent Events on the API port;
  the separate Socket.IO port is gone. Progress starts at zero for every
  run. (#527, #539, #548)
- A failed accompanied run says why it failed. (#554)
- A run reads the item definition of its own Test, not one with the same
  event name in another project. The item definition editor loads and saves
  the definition of the Test it shows. (#554, #557)
- A run looks its Test up in its own project; imported copies of a project
  share event IDs with the original. (#551)
- A site that pushes `gtag('consent', ...)` no longer fails the ecommerce
  reset check on a correct `{ ecommerce: null }` push. (#554)
- Recorded CSS selectors that start with `text` or `aria`, such as
  `textarea.comment`, are no longer taken for text or ARIA selectors. (#545)
- A failed `waitForElement` step saves a Failed run with its screenshot. A
  run whose result cannot be saved is not saved twice. (#545)
- Browsers are closed when a direct run fails during setup or is stopped
  while it starts. (#545)

### Projects, reports and data

- Importing a project export keeps its Tests, Runs and screenshots, also
  when the project already exists. A failed import is reported. (#550, #555)
- Deleting the latest Run also deletes its Tag Assistant recording. When
  two Runs share a time, the newer one is the latest. (#550)
- Editing a Test's spec changes that Test, not the project's first Test.
  (#550)
- Saving project information shows the saved project. (#550)
- Spreadsheet exports keep each sheet's project title and give every sheet
  a unique, valid name. (#550)
- History opens the Reports page filtered to the Test's event. (#555)
- A failed delete of Tests puts them back and says so. (#555)
- A Test created manually saves its dataLayer spec. (#555)
- Project and event IDs that point outside the project folder are refused.
  (#550)

### tag-build

- Spreadsheets are uploaded as CSV, including the "dataLayer Specs" column;
  the broken .xlsx upload is removed. (#537, #538)
- GA4 event parameters are written as `eventSettingsTable`, so a tag-build
  container imported into Tag Check keeps its parameters. (#529)
- Scroll and YouTube video tags fire on Tag Manager's Scroll Depth and
  YouTube Video triggers. The scroll depth is sent as `percent_scrolled`.
  (#546, #553)
- Nested dataLayer keys are sent under GA4-valid parameter names
  (`user.id` as `user_id`), and only their leaf values are sent. Import
  readiness warns about invalid or repeated parameter names. (#553, #556)
- The measurement plan template lists `lead_source` for `generate_lead`.
  (#553)
- The site counts container downloads and copies. (#528)

### Documentation site

- Japanese and Chinese headings get unique anchors, and the table of
  contents follows the page. (#546)
- The language picker works when the browser blocks storage. (#546)

## Upgrading

Install 3.2.0 over 3.1.1. The database, projects, Tests and Runs are kept.
