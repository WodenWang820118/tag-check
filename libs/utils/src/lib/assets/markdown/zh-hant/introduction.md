# 介紹

TagCheck 會檢查 Google Tag Manager（GTM）設定是否送出你規劃的資料。它會在 Chrome 中重播使用者旅程，擷取每一次 `dataLayer` 推送以及該事件的 GA4 請求，再將兩者與規格（spec）比對；規格就是你預期的事件與參數。

## TagCheck 的組成

- **專案**（Project）：一個受測網站及其設定，包括每次執行前要載入的值（例如同意聲明 cookie）、登入資訊、GTM 預覽連結與瀏覽器選項。
- **測試**（Test）：要檢查的一個 GA4 事件。每個測試都有一份**規格**，也就是它預期的 `dataLayer` 推送；以及一份**錄製**（recording），也就是觸發該事件的 Chrome Recorder 旅程。
- **執行**（Run）：測試錄製的一次重播。每次執行會進行兩項檢查：
  - **資料層檢查**（data layer check）：推送到 `dataLayer` 的事件符合規格；
  - **請求檢查**（request check）：該事件的 GA4 請求已傳送到專案的評估 ID，且其參數符合規格。
- **結果**（Result）：一次執行的發現：兩項檢查、擷取到的 `dataLayer`、原始請求、一張螢幕截圖與一段螢幕錄影。
- **狀態**（Status）：每個測試會顯示其最近一次執行的狀態：兩項檢查都通過時為 **Passed**，只有一項通過時為 **Partial**，兩項都未通過時為 **Failed**，首次執行之前則為 **Not run**。

## 執行過程

1. TagCheck 透過 Puppeteer 開啟 Chrome，載入專案的預載值，然後重播測試的錄製。
2. 它會記錄每一次 `dataLayer` 推送，並攔截網頁送出的 GA4 請求。
3. 它會將事件與請求和規格比對，將結果連同螢幕截圖與螢幕錄影一併儲存，並更新測試的狀態。

在 Accompanied Mode 下，執行會透過 GTM Preview（Tag Assistant）開啟網站，讓你也能觀察尚未發布之工作區中的代碼觸發。
