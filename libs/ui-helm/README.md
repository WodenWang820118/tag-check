# ui-helm

Spartan NG helm components used by `ng-gtm-sample`, generated by
`@spartan-ng/cli` from `components.json` and imported as
`@spartan-ng/helm/<component>`.

The files are generated source: keep local edits small so a component can be
regenerated. To add a component, preview it first:

```sh
pnpm nx g @spartan-ng/cli:ui --name=<component> --dry-run --no-interactive
```

Local changes to generated files:

- `carousel/src/lib/hlm-carousel.ts`: `scrollTo(index)` for the carousel's
  slide dots.

The `@nx/enforce-module-boundaries` rule is off for this library in
`.oxlintrc.json`, because the generated components import each other through
their `@spartan-ng/helm/*` entry points.
